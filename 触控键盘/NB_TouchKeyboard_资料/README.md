# NB_TouchKeyboard（第三方同类方案说明）

- **项目名**：NB_TouchKeyboard —— 一款面向 Windows 的触屏键盘（C++ 实现）
- **官方来源（代码）**：<https://github.com/zwj4031/NB_TouchKeyboard>（GPL-3.0）
- **发布 / 分享帖（图文介绍、截图与附件）**：
  - <https://www.wuyou.net/forum.php?mod=viewthread&tid=452923>
  - <https://bbs.wuyou.net/forum.php?mod=viewthread&tid=452628>
- **一句话概述**：仿系统触摸键盘的轻量实现，支持全键盘 / 九宫格布局、浅色 / 深色主题、
  右键菜单、Fn 功能键等，可作为系统触摸键盘缺失时的替代方案之一。
